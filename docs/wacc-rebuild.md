# LLY WACC Rebuild Plan and Evidence Boundary

The prior LLY DCF used an 8.5% WACC as analyst judgment. That was the model's largest unsupported value driver, so this Project 2 panel labels it as the **most distrusted input** and bounds it to 7.5% through 10.0% rather than presenting it as an observed fact.

Before any adoption decision, rebuild WACC on a single documented as-of date with these saved components: risk-free rate, beta source and lookback, equity-risk premium method, pre-tax cost of debt, marginal tax rate, debt weight, and equity weight. Preserve every raw source and the calculation in the same folder. Do not mix a later market price with older WACC inputs without a date-boundary disclosure.

The available point-in-time evidence from Lab 17 is DGS10 at 5.28% as known on 2026-10-05. It is not a current WACC component and should not be substituted for a same-date cost-of-capital build. The LLY 2026-11-16 close of $1,431.67 is likewise a context signal, not a WACC input.

This keeps the panel useful for sensitivity while avoiding a false claim that the WACC has already been fully sourced.
