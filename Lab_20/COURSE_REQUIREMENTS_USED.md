# Course Requirements Used

This local reference records the requirements applied when building this readiness package. The linked course pages in `SOURCES.md` remain the controlling sources.

## Lab 20 readiness check

- A stranger must be able to reach the decision from the GitHub repository alone.
- The repository needs one README command, visible decision output, a decision memo consistent with the output, validation/AI-use documentation, and working video/transcript links.
- A partner must perform a README-only cold run and record the command, first failure, elapsed time, and result location.
- Before running a load-bearing changed input, the student must personally predict its direction and decision effect with AI closed, then commit/push that prediction. The run must preserve before/after results and explain the outcome.
- The student must fix the first cold-run failure or record a clean run, state one committee decision line with a reversal condition, and submit GitHub links to the required artifacts.

## Project 2 requirements applied

- A Python web app—not only a notebook or one-time script—must run from the README.
- The app must show the Lab 13 mandate, two transparent baselines, the constrained portfolio, and rule-specific mandate verdicts.
- It needs a point-in-time signal plus data card, a stress run and stop condition, a Locked Changed-Input Record, allocation range/recommendation/triggers, and AI/education disclosures.
- Submission requires the GitHub repository, `docs/decision-memo.md`, `docs/validation-and-ai-use.md`, three YouTube video links with transcripts, and a manifest of locations.

## Boundaries of this package

The code, output, memo, source ledger, data card, stress calculation, test suite, cold-run record, and checkout template are supplied. The student reports completing the real partner cold run and AI-off pre-run prediction/commit. Actual GitHub URLs, the actual elapsed time, and the student's own video recordings/transcripts remain personal evidence and must be added truthfully.
