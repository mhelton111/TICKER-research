# Meridian Lab 14

This folder contains the completed Lab 14 portfolio-baseline submission and the course instructions used to build it.

Run `python portfolio.py` to reproduce the three baseline calculations. Run `python mandate.py` to confirm that Candidate E, the Meridian benchmark, fails the 3.0% reserve requirement.

Run `python -m unittest -v test_lab14.py` to execute the known-answer and validation tests.

The complete written submission, including the partner Q and A section, is in `Lab_14_Submission.md`.
